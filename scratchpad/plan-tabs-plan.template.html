THE TAB STRIP

Every plan you open gets a tab, like a browser. The tab you are on is lit with the blue underline; a tab with unsaved marks wears an amber dot; a tab whose plan is still arriving shows a tiny spinner with how much has come. The + at the end opens the plan you are on in a fresh tab (a second, clean sketch of the same sheet). The strip scrolls sideways when there are many.

THE RULES THE REAL THING WILL KEEP

  • Tabs survive a refresh. The strip is remembered on this machine, per job — reopening the studio brings back the same tabs on the same plans, each remembering its page and zoom. Unsaved marks already survive a refresh today (the studio keeps them on this machine); each tab’s marks are kept the same way.
  • The question is asked only when there is something to lose. A tab with no unsaved marks closes silently. With unsaved marks: “Your work isn’t saved. Save to Google Drive?” — Yes files it exactly as the Save button does today (same Annotated Plans folder, same naming, same version numbers), No closes and discards. Nothing else about saving changes.
  • Plans download ahead, quietly. When a plan opens, the other plans in its Engineered Plans folder start downloading one at a time in the background — the current plan always first, and it is never slowed down by the others. Each row and tab says “downloading… 40%” until its copy is here; after that, switching to it is instant.
  • The copies are thrown away when you leave; the tabs are not. Closing the studio drops every downloaded copy (nothing piles up on the machine) but keeps the tab strip — next time, the tabs come back and their plans download again.
  • The toolbar is not touched. No tool moves, no button changes; the strip takes only the empty middle of the top bar. On a phone, where that bar has no middle, the strip sits on its own thin row under the bar.

TWO CALLS I MADE — SAY IF EITHER IS WRONG

  • The drawer’s plan pane gets the same strip. The pane in the apartment window is the same viewer, so it gets the same tabs, on a slim row of its own under the two bars there (its bars have no spare middle). If you want tabs only in the full-screen studio, that is one switch.
  • Tab look: Chrome’s manner — rounded top, the lit one brighter with a blue underline, amber dot for unsaved, × on each tab (always visible on the touchscreen). Drawn above with the studio’s real colours; if you want them shaped differently, mark this page up.
