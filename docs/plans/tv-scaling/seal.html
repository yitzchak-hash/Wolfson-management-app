The TV Size Plan

✦ Sealed · 10 picks · 2026-09-08

One number per TV, applied once, with no hidden ceilings — the dial always moves the picture, the TV answers out loud, and the red button walks you to readable in measured steps.

Every pick, locked

1

True zoom. 160% means everything is genuinely 1.6× — the grid reflows; fewer, bigger cards.

2

One pipeline, all views. Board, diagram, dashboard — the same number, applied once at the root.

3

The TV answers. Any size change flashes “Display size 90% → 160%” on the wall itself.

4

The red button walks. Bounded steps with a real re-measure between presses.

5

The dial beats the slice. On a region panel, turning up grows past the slice’s edges — the slice is the framing at 100%.

6

The shared size greets newcomers. A panel with no saved size starts from it; its first own change takes over.

7

Ceiling 300%, on every control that sets the number.

8

One press ≤ +25% of the current size, toward the measured need.

9

The bar keeps its own dial. Buttons size for the hand at the panel; content sizes for the eyes across the room.

10

A test pattern on the wall. One press draws rulers and sample words at known real sizes.

Also sealed from the diagnosis: an old size in a TV tab’s web address is bootstrap-only — the saved per-panel size always wins. And the supersession rule: where any older note disagrees with this plan, this plan wins; older records stay as history.

The build order

B1

The one number. Saved per-panel size → address-bar bootstrap → shared default. Ceiling 300% everywhere.

B2

Root zoom per view. The dashboard renders inside one sharp layout-zoom like the board and diagram already do; every hidden per-element ceiling is deleted.

B3

The confirmation chip. The wall flashes old → new whenever its size changes after first load.

B4

The walking red button. Settings card and the TV’s own report button step, measure, and keep offering until the words clear the line.

B5

The test pattern. Rulers and sample text at known real pixels, self-dismissing.

B6

Proof. The probe that exposed the dead button becomes the standing test: sizes must grow in proportion; a stale address-bar size must lose; the chip must appear; the ceiling must hold.

B7

The record. What’s New, the developer notes, and this folder committed together.
