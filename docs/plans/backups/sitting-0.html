Your questions, answered

"Was the old JSON really just Wolfson?"
Yes. Each old file holds only the workspace that was open on the computer that made it, plus the shared parts (stages, users, board settings). I opened all 580 files since 14 October: every one was Wolfson. The Job Board and Netiv were never in Drive.
"Are Snapshot history, Google Drive auto export and Manual backup the same thing?"
No. They are three older, partial tools, built at different times. See the cards below: each covers less than the new full backup.
"I thought the preview would be for the JSON."
It can be both. Today Preview opens the new full backups. Opening an imported file in the same preview is question 7 below.

Sitting 0 · questions

The three old tools: keep, change or retire?

The full backup and Google's backup already cover everything the old tools did, and more. The question is which old pieces still earn a place.

3

The hourly one-workspace files to Drive (Google Drive auto export)

AStop making them. The full backup replaces them. Old files stay in Drive as history.
BKeep making them alongside the full backup.
★ A: they hold one workspace, so they can mislead (they looked complete and weren't), and they add ~24 files a day.
4

Snapshot history (restore points on one computer)

ARetire it. Its job moves to the full backups list.
BKeep it as a quick extra.
★ A: it lives on one computer and holds only part of the data. Two different restore lists would be confusing.
5

"Download a backup to my computer" button

AKeep it, but it downloads the full backup (every workspace).
BRemove it. Drive holds them all.
★ A: a copy you hold yourself, outside Google, is a classic safety rule ("one copy somewhere else").
6

Restoring from a backup file (Import)

AAny backup, from the list or a file you choose, opens in the Preview first. Restore is pressed there and writes to the cloud.
BOnly backups from the Drive list. No file import.
★ A: one way to restore, always with a preview, whatever the backup's source.
7

Old one-workspace files (like this morning's): can they be previewed and restored too?

AYes, previewed; restore puts back only that workspace (the file has nothing else).
BNo, full backups only.
★ A: the old files are the only history before today; it would be a shame to lock them out.
