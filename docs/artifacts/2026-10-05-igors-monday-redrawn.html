3 · Activity — what was built today, and the plan

Built today

  • The Job Board's Activity page shows every workspace's activity, each row tagged with its workspace.
  • Every entry is a plain sentence: "Igor uploaded 5 photos", "Igor started work here — Wall Units". No field names like "viewed", "completedAt" or "photo_uploaded".
  • Repeats collapse: five uploads in a row by the same person on the same apartment are one line you can open.
  • Stage entries speak the new way: "Igor marked Registers done", not "changed stage Wall Units → Registers".

The plan: one card per person per day

Each visit to an apartment becomes one line: when it started, what stage, the pictures, when it closed, and where the apartment stands now. Above it, the things that look wrong are flagged before anyone has to read the whole day.
