# Artifacts — every page published for this project, in order

Pages the owner reviews and approves live on claude.ai as "artifacts". This
folder keeps a COPY of each page as it was published (dated, never
overwritten — a re-publish is a new dated file), so the plan a decision was
made on can be read without the link. Older pages were built from templates
that live in `scratchpad/` (named below); their built HTML was not saved at
the time and can be rebuilt from the template, or read at the link.
