WHAT WILL BITE YOU
The build list ends with a "Rules this build must not break" section. Read it
before the first edit, not after. In particular:
- There are at most 12 serverless functions allowed under /api and the folder is
  full. Adding a 13th turns every deployment red while the local build stays
  green. Item 8 uses the existing /api/drive-fetch.
- New user-facing strings come from the strings objects. A new
  ContractorUiStrings key must be optional with a fallback — those are
  user-edited and stored with no merge-fresh, so a required key renders blank
  for everyone who used the app before today.
- Width tests are subscribed matchMedia listeners, never a value cached at
  mount. A folding phone changes width with the window open and breaks anything
  cached, first.
- photoIds on ContractorNote is the ONLY new field in the list, and it rides a
  collection that is already persisted, exported, imported and synced. If you
  add any other state key, it goes into persist + export (top level) + import
  and you re-run node scratchpad/backupaudit.mjs.

DONE MEANS

Two harnesses carry standing pre-existing failures unrelated to this work —
boardsize.mjs (left-edge auto-pan) and touchpan.mjs (pinch zoom). Confirm they
fail identically with your changes stashed before blaming yourself for them.
